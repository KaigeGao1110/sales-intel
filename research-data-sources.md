# Research: Company Data Collection Sources for MVP

## Task
Research the best free/low-cost APIs and data sources for company research in Phase 1 MVP.

## Focus Areas
1. **News APIs** - Free or cheap news aggregation (NewsAPI, Bing News, Google News rss)
2. **Company Info APIs** - Company size, industry, description (Clearbit, Apollo, Crunchbase free tier)
3. **Review Sites** - Glassdoor, G2, Trustpilot (scraping approach or APIs)
4. **Job Postings** - LinkedIn, Indeed (for hiring trends that signal growth/problems)
5. **Funding Data** - Crunchbase free tier, Pitchbook (for funding rounds)
6. **Search API** - SerpAPI for Google search results, or free Brave Search API

## Output
Provide:
- List of recommended APIs/sources with costs (free tiers)
- Pros and cons of each
- Which to use for MVP (prioritize free)
- Simple Python code snippets for top 2-3 sources
